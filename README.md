# AI-Powered App Development Training

This repository contains practice code, exercises, and projects for the **AI-Powered App Development** training course.

## 📅 Course Overview

- **Week 1:** Python Fundamentals & Machine Learning Basics
- **Week 2:** NLP to Generative AI
- **Week 3:** Building AI Chat Applications with LLM APIs
- **Week 4:** Knowledge Base & Vector Databases
- **Week 5:** Retrieval-Augmented Generation (RAG) Applications

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/paingzinyemaung/ai-training.git
   cd ai-training
   ```

2. **Set up virtual environment:**
   ```bash
   python -m venv .venv
   source .venv/Scripts/activate  # On Windows (Git Bash)
   ```

3. **Run code:**
   ```bash
   python Day_1/dictionary.py
   ```
